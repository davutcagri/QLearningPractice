# QLearningPractice

A small project I made while learning the basics of Q-learning.

The agent starts in a simple grid maze and learns how to reach the goal using rewards and penalties.

I implemented the Q-learning logic from scratch using NumPy and added a simple Matplotlib visualization to see the learned Q-values.

## Run

Install the dependencies:

```bash
pip install -r requirements.txt
```

Then run:

```bash
python main.py
```

This was mainly a practice project to better understand how Q-tables, rewards and exploration work.
